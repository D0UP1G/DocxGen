# DocxGen — план и состояние

## Выполнено

- [x] Четыре обязательных типа документов в единой схеме.
- [x] Обязательные реквизиты синхронизированы со стартовым перечнем.
- [x] Локальная обработка черновика с сохранением фактов и без выдумывания даты/сумм.
- [x] Опциональный AI-режим через opencode/Podman с локальным fallback в режиме `auto`.
- [x] Отдельные endpoints `/api/process` и `/api/generate`.
- [x] Двухшаговый UI: обработка, ручное редактирование текста и реквизитов, скачивание.
- [x] Два программных оформления по правилам стартового пакета.
- [x] Генерация редактируемого DOCX напрямую в OOXML.
- [x] Placeholder-ы для незаполненных обязательных реквизитов.
- [x] Обработка ошибок без потери исходного текста.
- [x] Backend unit-тесты для валидации, локальной обработки и DOCX.
- [x] README с командами запуска, API, переменными окружения и ограничениями.

## Дополнительные возможности

- [ ] История и версии документов.
- [ ] Загрузка произвольных DOCX-шаблонов и их автоматический разбор.
- [ ] Очередь фоновых задач и ограничение параллельных AI-вызовов.
- [ ] Промышленная аутентификация, аудит и rate limiting.
