## Инструкции

### 0. Запрет на галлюцинации (ВЫСШИЙ ПРИОРИТЕТ)
- Не придумывай должности, ФИО, организации которых нет в черновике
- Не добавляй даты, числа, суммы которых нет в черновике
- Не интерпретируй и не домысливай — если информация отсутствует, верни null
- Не используй внешние знания — только то, что написано в черновике

Примеры:
- Если черновик говорит «нужно посмотреть документы», НЕ пиши «Директору Иванову И.И.» — верни addressee: null
- Если в черновике нет даты, НЕ подставляй сегодняшнюю — верни date: null
- Если указано «бюджет около 2 млн», НЕ пиши «2 500 000 рублей» — верни точное значение из черновика
- Если нет упоминания организации, НЕ придумывай аббревиатуру ООО/ОАО — верни addresseeOrg: null

### 1. Исправление текста
- Исправь орфографические и пунктуационные ошибки
- Сохрани стиль и тон черновика
- Не меняй фактическое содержание
- Не добавляй информацию, отсутствующую в черновике

### 2. Извлечение полей
Для каждого поля из списка выше:
- Определи тип поля (extract или derived) — указано в описании поля
- Для полей типа extract: найди соответствующее значение в черновике, верни точную цитату (quote)
- Для полей типа derived: создай значение на основе текста черновика, но НЕ выдумывай факты
- Верни нормализованное значение (value)
- Если поле не найдено или нет оснований для derivation — верни null

### 4. Формат ответа
Верни ТОЛЬКО JSON-объект (без markdown-обёрток, без пояснений):

```json
{
  "title": "Заголовок документа или null если не нужен",
  "body": [
    "Первый абзац исправленного текста",
    "Второй абзац"
  ],
  "fields": {
    "fieldKey": {
      "value": "Нормализованное значение",
      "quote": "Точная цитата из черновика"
    },
    "notFoundField": null
  },
  "changes": [
    "Описание исправления 1",
    "Описание исправления 2"
  ]
}
```

### Важно
- `title` — если заголовок не нужен или неизвестен, верни null
- `body` — массив абзацев (каждый непустая строка, максимум 50 абзацев)
- `fields` — только те ключи, что есть в списке полей выше
- `quote` — ДОЛЖЕН быть точной цитатой из черновика (без изменений)
- `changes` — максимум 10 изменений; пустой массив если ничего не исправлено
