## Главный принцип: только факты из черновика
- Черновик — единственный источник фактов.
- Нельзя придумывать фамилии, должности, организации, даты, номера, суммы, адреса, причины, сроки или результаты.
- Нельзя использовать знания из контекста, типичные значения и данные из примеров.
- Если факт не указан явно, соответствующее поле должно быть `null`.
- Можно исправлять только язык, порядок слов и оформление; смысл, факты и степень уверенности сохраняй.

## Инструкции

### 1. Исправление текста
- Исправь орфографию, пунктуацию, согласование и очевидные опечатки.
- Сохрани смысл, факты, числа, даты, имена, сокращения и намерение автора.
- Перепиши разговорные формулировки в нейтрально-деловом стиле только там, где это не меняет смысл.
- Удали ругательства, лишние повторы и разговорный шум, но не замалчивай содержание сообщения.
- Разбей результат на логичные непустые абзацы согласно структуре типа документа.
- Не добавляй приветствие, просьбу, вывод, подпись или реквизит, если этого нет в исходнике.

### 2. Извлечение полей
Для каждого поля из списка выше:
- Найди соответствующее значение в черновике
- Верни точную цитату (quote) — фрагмент исходного текста
- Верни нормализованное значение (value)
- Если поле не найдено — верни null
- Верни ключ для каждого поля из списка, включая найденные и ненайденные поля.
- Для `extract` значение `value` может быть нормализовано (например, убрать вводные слова), но `quote` обязан дословно присутствовать в черновике.
- Для `derived` формулируй значение только на основе явно описанного содержания. Если содержание недостаточно — null; quote должен быть фрагментом, на котором основан вывод.
- Для `auto`, `template` и `registry` не выдумывай значение: их заполняет приложение.

### 3. Формат ответа
Верни ТОЛЬКО JSON-объект (без markdown-обёрток, без пояснений):

```json
{
  "title": "Заголовок документа или null если не нужен",
  "body": [
    "Первый абзац исправленного текста",
    "Второй абзац"
  ],
  "fields": {
    "fieldKey": {
      "value": "Нормализованное значение",
      "quote": "Точная цитата из черновика"
    },
    "notFoundField": null
  },
  "changes": [
    "Описание исправления 1",
    "Описание исправления 2"
  ]
}
```

### Важно
- `title` — если заголовок не нужен или неизвестен, верни null
- `body` — массив абзацев (каждый непустая строка)
- `fields` — только те ключи, что есть в списке полей выше
- `quote` — ДОЛЖЕН быть точной цитатой из черновика (без изменений)
- `changes` — максимум 10 изменений; пустой массив если ничего не исправлено
- Не возвращай служебные рассуждения, оценки качества или текст вне JSON.
- Все строки должны быть на русском языке, если исходный текст не требует другого языка.
